# 受邀账号独立词库

网站：https://toefl-vocab-study.rayzhaory.chatgpt.site

每位受邀者使用自己的 ChatGPT 账号。词单、词条、复习计划、错词与测试记录、已保存的拍照批次和作答各自独立；新账号从空词库开始。导入与导出仅作用于当前账号。

在另一台电脑打开同一个网址、登录同一账号即可继续学习。离开原设备前确认“已同步”；短暂断网产生的操作保留在原设备，恢复联网后补传。原照片及未确认草稿仍仅在当前设备。

页面顶部显示当前账号邮箱。若在同一浏览器换号，旧页面将停止读取和上传，并提示刷新；原账号的待上传操作会保留，切回原账号后可以继续同步。旧版本页面也需刷新后才能上传。

网站保持受限访问。所有者在 Sites 的分享设置中按邮箱邀请访客；访客使用获邀邮箱对应的账号登录。移除邀请通过平台分享设置操作。访问权限与数据库记录归属分别控制。

## 旧数据归属

发布前已完整备份生产 D1 八张业务表，备份位于项目上级 data/backups/before_multi_account_20261102/d1-backup.json；当时为 119 个词、3 个词单、214 条复习日志、6 个操作回执，云端版本为 6。

LEGACY_OWNER_EMAIL 是通过 Sites 所有者信息核实后设置的服务器秘密配置。只有该邮箱的真实已验证登录身份，才会在首次数据请求时接收原单人空间。服务器在一次 D1 原子批次中复制全部八张表及操作回执，并记录 account_migrations 的唯一迁移归属。原 owner 空间保留为历史快照，普通账号接口无法访问它。并发请求与重试不会重复迁移，删除后也不会重新复制。

若目标账号已有数据，迁移返回 409 并保留两份数据，需维护者备份后做合并；不覆盖现有记录。配置缺失时不会把旧数据分配给任何访问者。用户 ID 仅取自 Sites 注入的身份头，不接受请求正文指定归属。X-Toefl-Account 只校验页面是否仍属于当前登录账号，不授予身份。

## 验证与恢复

新增 account_migrations 表，现有迁移文件保持不变。29 项自动测试全部通过，验证账号隔离、导入导出、相同操作 ID 的独立性、一次性迁移及原同步功能。生产备份在隔离的本地 D1 完成真实迁移演练，八张表的数据逐条一致，保留 119 个词、3 个词单和 214 条复习记录；正式生产构建已通过。

上线后的数据恢复应先导出各账号完整备份，再按账号合并。已有账号独立写入后，不可直接回滚到旧版共享数据空间代码；旧 owner 快照不包含新版产生的记录。应使用保留账号隔离的代码修复或按账号恢复。

真实访客账号与两台个人设备的 ChatGPT 登录仍需各自操作；本地浏览器测试使用明确隔离的测试会话与真实本地 D1，不代替平台访客授权检查。
