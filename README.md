# 托福词汇助手云端版

仅本人使用的私有 Sites 网站，保留原网页操作与拍照测词流程。D1 保存正式数据；浏览器保存当前账号的缓存和待上传操作。原照片与未确认校对草稿只留在当前设备。

两台设备登录同一 ChatGPT 账号，访问同一网站即可同步。新增、复习与照片批次通过幂等操作上传，删除记录阻止旧数据复活。同步页支持合并旧 version 2/3 JSON、完整备份与手动同步；完整备份包含尚未上传操作。

## 本地开发

执行 npm install、npm run generate:ui 和 npm run dev。页面生成器位于 ui-source/build_web.py；生成的 lib/vocab.html 不包含个人词库或学习历史。开发预览使用平台本地模拟登录，与正式身份校验分开。

运行 npm test 验证操作规则、真实本地 D1、双浏览器同步和识别适配器。浏览器测试使用当前工作环境提供的 Playwright；其他环境需调整测试中的运行库路径。

## 云端配置与发布

使用 Sites 官方构建及私有发布流程。DB 是 D1 绑定；drizzle 中已发布迁移不可重写，后续变化追加迁移。运行配置为 PHOTO_VISION_ENDPOINT、PHOTO_VISION_MODEL 和秘密 PHOTO_VISION_API_KEY。前端只读取配置状态。临时 BOOTSTRAP_TOKEN 仅供首次受控迁移，迁移后删除并重新部署。

重新部署不会初始化学习数据。回滚代码使用平台已保存版本；数据恢复先完整导出，再通过同步页合并备份。不得使用旧客户端全量覆盖云端数据。生产后台不得接受客户端自行声明的用户身份，使用平台注入的认证信息。

真实识别测试使用自制词汇书样式页；真实接口成功与模拟异常测试分别记录，实际书页识别仍需用户校对。
